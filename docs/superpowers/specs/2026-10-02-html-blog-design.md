# 单文件离线 HTML Blog 设计

## 目标

基于当前仓库的全部记录内容，生成仓库根目录的 `index.html`。用户可直接双击打开并浏览，无需本地服务器、网络连接或 CDN。

## 内容范围

- 收录仓库中的 Markdown、HTML 和 Jupyter Notebook 文件。
- Markdown 渲染标题、段落、列表、表格、代码块、链接和本地图片。
- Notebook 渲染 Markdown 单元、代码单元及已有输出，不执行代码。
- HTML 文件展示源码，并提供打开原文件的入口。
- 图片和原 HTML 文件继续使用仓库相对路径，不嵌入 Base64。
- 收录扫描到的全部 38 个 Markdown、124 个 HTML 和 18 个 Notebook 文件；仅忽略 `.git` 内部文件。

## 架构

新增一个仅使用现有运行环境或标准库的生成脚本。脚本扫描仓库文件，解析内容与元数据，按路径建立分类，最终写出一个静态 `index.html`。

生成后的页面将以下内容直接写入单个 HTML 文件：

- 文章正文和元数据
- 分类与目录数据
- 全文搜索数据
- 页面样式
- 浏览交互脚本

页面不在运行时读取 Markdown 或 Notebook，因此兼容 `file://` 方式打开。

## 页面结构

- 顶部区域显示站点名称、内容统计和主题切换。
- 左侧栏显示全文搜索与按仓库路径组织的文章目录。
- 主内容区默认显示仓库简介与分类统计，选择文章后显示正文。
- 小屏幕下目录折叠为可开关面板。
- 阅读区提供文章标题、类型、相对路径和正文。

## 内容呈现

Markdown 使用生成脚本内的最小解析逻辑转换为安全、可读的 HTML。代码和普通文本必须转义；仓库内相对链接按源文件目录解析。

Notebook 读取 JSON，依次展示 Markdown、代码及已保存输出。富文本输出优先使用纯文本或图片表示；不执行单元格。

HTML 示例以转义后的源码展示，并链接到原文件。页面不把示例直接注入主文档，避免样式和脚本污染博客界面。

## 搜索与导航

搜索在浏览器内完成，匹配标题、路径和纯文本正文。结果即时更新，点击后打开对应文章。目录按顶层目录分组，并显示每组文章数量。

## 错误处理

- 单个文件解析失败时生成错误文章，显示文件路径和简短原因。
- 单个本地资源缺失不阻断其他内容生成。
- 无可收录文件时仍生成可打开的空状态页面。
- 生成脚本不得修改任何原始记录文件。

## 验收标准

- 根目录生成 `index.html`，双击后可离线浏览。
- 收录扫描规则覆盖的全部 Markdown、HTML 和 Notebook 记录。
- 目录、全文搜索、文章切换、主题切换和移动端布局可用。
- Markdown、Notebook 和 HTML 三类内容均可阅读。
- 页面不依赖 CDN 或远程资源。
- 提供一个最小自动检查，验证输出文件存在、文章数量与扫描结果一致，并且没有远程依赖。

## 非目标

- 不执行 Notebook。
- 不提供评论、登录、后台管理或在线发布。
- 不引入站点框架、前端构建工具或新依赖。
- 不将全部图片转为 Base64，也不保证复制单个 `index.html` 到仓库外仍能显示本地资源。
